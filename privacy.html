Privacy Policy

Last updated: 6 November 2026

Autopilot is a personal tool used only by its owner to upload videos to the owner's YouTube channel, youtubeclips2001.

Information accessed

With the owner's permission, Autopilot uses Google's OAuth to get the youtube.upload permission for the owner's own Google account. It uses that permission only to upload videos and set their title, description, tags and privacy setting. It doesn't read, collect or store any other Google user data.

Storage and sharing

The OAuth access token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. Autopilot doesn't use cookies or analytics.

Google API Services

Autopilot's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Autopilot uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
